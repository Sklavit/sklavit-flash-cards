# Flashcards PWA

A simple, elegant flashcard learning application built as a Progressive Web App (PWA) optimized for iOS.

## Features

- **10 Predefined Flashcards**: Learn with 10 curated question-answer pairs
- **Random Shuffle**: Cards are shuffled on load and can be reshuffled anytime
- **Flip Animation**: Smooth 3D flip animation to reveal answers
- **iOS Optimized**: Full support for iOS PWA with safe area insets
- **Offline Ready**: Works offline with service worker caching
- **Responsive Design**: Beautiful gradient UI that works on all screen sizes

## Usage

1. Open the app on your iOS device
2. Tap "Add to Home Screen" from Safari's share menu
3. Launch the app from your home screen
4. Tap any card to flip and see the answer
5. Use Previous/Next buttons to navigate
6. Use Shuffle button to randomize card order

## Technology

- Pure HTML, CSS, and JavaScript
- No dependencies or frameworks
- Service Worker for offline functionality
- CSS 3D transforms for flip animation
